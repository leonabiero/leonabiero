### 🚀 What I'm Working On

Right now, my main focus is **[Reflection Space](https://github.com/leonabiero/reflection-space)** — a modern, privacy-first web application designed for mindful journaling, daily mood tracking, and personal reflection. 

* **The Vision:** Creating a distraction-free digital environment that helps users foster daily mindfulness, track emotional well-being over time, and gain valuable insights into their personal growth.
* **Core Focus:** Clean UX/UI, end-to-end data privacy, responsive design, and smooth user interactions.
